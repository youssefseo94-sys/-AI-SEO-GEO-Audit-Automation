# 🚀 AI-SEO-GEO Audit Automation Engine

> An advanced Python-based site auditing tool designed for **Technical SEO**, **Answer Engine Optimization (AEO)**, and **Generative Engine Optimization (GEO)**.

---

## 📌 Key Capabilities

- **Technical SEO Diagnostics:** Crawls sitemaps, analyzes HTTP status codes, checks canonical tags, indexing directives (`noindex`), and H1/Meta tag structures.
- **AEO Readiness (Answer Engine Optimization):** Evaluates Schema Markup (JSON-LD) and structure for rich snippets and conversational answer engines.
- **GEO Optimization (Generative AI Engines):** Scans page readability, internal linking architecture, and content depth required for generative AI models (ChatGPT, Perplexity, Google AI Overviews).
- **Core Web Vitals & PageSpeed:** Parses Google PageSpeed Insights API for real-world performance metrics.
- **Automated Reporting:** Generates clean, actionable Excel data reports alongside executive summary PDFs for client delivery.

---

## 🛠️ Tech Stack & Libraries
- **Language:** Python 3.x
- **Libraries:** `requests`, `beautifulsoup4`, `pandas`, `openpyxl`, `reportlab`
- **Platform:** Google Colab / Local Python CLI
